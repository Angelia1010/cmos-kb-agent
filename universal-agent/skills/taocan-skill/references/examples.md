# 坐席话术示例与标准应答

## 示例1: 客户咨询99元套餐

客户: "99元套餐包含什么？"

标准应答:
"您好，99元套餐包含:
- 月费(每月): 99元
- 国内通用流量: 20GB
- 国内通话: 300分钟
- 合约期(月): 12个月
温馨提示: 流量超出后按5元/GB计费，当月达量50GB后限速至1Mbps。"

## 示例2: 客户要求对比套餐

按"月费→流量→通话→短信→合约期"顺序排列:
| 项目 | 99元套餐 | 129元套餐 |
|------|---------|----------|
| 月费(每月) | 99元 | 129元 |
| 国内通用流量 | 20GB | 40GB |
| 国内通话 | 300分钟 | 500分钟 |
| 合约期(月) | 12 | 24 |
